# Tradia

Dashboard de análisis de mercado de criptomonedas. Combina datos de mercado (CoinGecko) y
noticias (RSS de CoinDesk/Cointelegraph) para generar un resumen de tendencia y sentimiento por
moneda o del mercado general, mediante un motor de reglas propio (sin APIs de pago ni claves
externas).

> Herramienta educativa. No constituye asesoría financiera.

## Requisitos

- Node.js 18+

## Arranque

```bash
npm install
npm --prefix backend install
npm --prefix frontend install
npm run dev
```

- Backend: http://localhost:4000
- Frontend: http://localhost:5173
